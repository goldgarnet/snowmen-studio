# 팀이 정할 규칙 (5건)

이미 고친 버그는 여기 없습니다. 규칙의 뜻이 갈려서 **팀이 정해야 하는 것만** 모았습니다.
정하기 전까지 엔진은 지금 동작 그대로입니다.
어느 쪽으로 정해도 지금 등록된 팀 풀이는 바뀌지 않습니다.

2026-11-03에 8건을 닫아 `bugs/`로 옮겼습니다.
- 포탈 6건(B-014·B-018·B-019·B-020·B-021·B-022)과 주황 버튼 1건(B-023): 팀이 포탈과 주황 버튼·주황 벽을 게임에서 빼기로 해서 닫았습니다.
- B-025(레이저 발사면 쪽 밀기): 사용자가 지금 동작대로 두기로 했습니다. 버그가 아닙니다.

## 맵으로 보는 법

파일마다 **맵 코드와 수순**이 표로 들어 있습니다.

1. Studio '맵 제작'에서 **레벨 코드 불러오기**에 맵 코드를 붙여 넣습니다.
2. 시뮬레이터에서 수순대로 둡니다.
   - `U` `D` `L` `R` = 방향키
   - `W`(대기) = **스페이스**. W 키는 위로 이동이니 누르지 마세요.
   - `M`(영혼 순환) = M 키
